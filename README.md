# Restuarant Management & Reservation Website

📌 **Project Overview**

This project is a modern and user-friendly Restaurant Management & Reservation Website developed using HTML5 and CSS3. It is designed to showcase restaurant services, delicious food items, and reservation facilities through an attractive homepage. The website features a stylish background, animated food images, a navigation menu, and a booking button to provide visitors with a smooth browsing experience.

- **Frontend:** HTML5, CSS3
- **Main Components:** Font Awesome Icons, CSS Keyframe Animation, Custom Styling

The main goal of this project is to create an attractive restaurant website where visitors can explore restaurant information, view food presentations, and easily access the table reservation option.

📌 **Features**

- Modern and visually appealing restaurant homepage.
- Full-screen background image with a dark overlay effect.
- User-friendly navigation bar with different menu options.
- Animated food image using CSS rotation effects.
- Attractive hero section with heading and description.
- Book Table button for table reservation.
- Font Awesome icons for better visual appearance.
- Custom CSS styling with attractive colors and typography.
- Clean and organized website layout.
